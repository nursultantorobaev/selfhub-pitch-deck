# SelfHub AI Pitch Deck

A professional pitch deck presentation for SelfHub AI.

## Files

- `index.html` - Main presentation file

## Required Images

Place the following image files in the same directory as `index.html`:

1. **Logo.png** - SelfHub AI logo (used in Slide 1)
2. **Skip_the_calls_and_queues__version_1.png** - Operational pain illustration (Slide 2)
3. **More_than_just_beauty__version_1.png** - Wellness and beauty feed illustration (Slide 3)
4. **Tool_2__Booking_&_Scheduling_version_1.png** - Booking & scheduling tool screenshot (Slide 6)

## How to Use

1. Open `index.html` in any modern web browser
2. The presentation displays as a vertical scroll of slides
3. Each slide is optimized for 1280x720 resolution (16:9 aspect ratio)

## Notes

- The presentation includes 7 slides covering:
  - Title & Vision
  - The Problem
  - Inspiration Feed
  - Competitive Landscape
  - SaaS Model & Pricing
  - Growth Targets
  - The Team

- If images are missing, placeholder boxes will appear automatically
- All styling is embedded in the HTML file for easy sharing
